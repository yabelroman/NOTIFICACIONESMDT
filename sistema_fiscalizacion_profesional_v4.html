📊 Gestión de Datos, Avance e Integración

☁️ Sincronización Multi-Dispositivo (Compartir entre Celulares y PC)

GitHub Pages

💡 ¿Por qué no se ven los datos al abrir el enlace en otro celular?
GitHub Pages es un alojamiento gratuito de archivos web estáticos (no posee base de datos central). Cada celular o computadora guarda sus datos y fotos en el almacenamiento privado de su propio navegador (localStorage). Para que otro dispositivo vea tu trabajo, dispones de dos soluciones inmediatas:

📱 Opción A: Compartir por WhatsApp o Drive (Inmediato)

1. En el celular de campo presiona "Descargar Copia de Avance".
2. Envía el archivo .json por WhatsApp a tu PC o supervisor.
3. En el otro dispositivo, abre la web y presiona "Importar y Agregar Datos". Los datos se sumarán acumulativamente sin borrar nada.

🌐 Opción B: Sincronización en la Nube en Tiempo Real

Puedes conectar una base de datos en la nube gratuita (como Firebase Realtime Database o un Webhook de Google Apps Script) para que todos los celulares envíen y reciban los registros con un solo clic.

📥 Importar y Agregar Datos

Sube un archivo JSON de respaldo. Los registros importados se agregarán a los existentes sin borrar tu avance. Después de seleccionar el archivo, podrás elegir si deseas procesar primero el número de muestreo menor o el mayor que contiene el archivo. Los registros se agregarán con numeración correlativa después del último número registrado.

La elección determina el orden de los registros importados: del número original menor al mayor, o del mayor al menor. No se eliminan registros existentes y se evitan duplicados.

📗 Exportar a Excel (CSV)
